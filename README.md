# DLS26Tournament Hub 🏆⚽

DLS26Tournament Hub is a custom tournament platform made for managing Dream League Soccer competitions between friends.

The website allows players to follow DLS Cups, view tournament brackets, track statistics, compare rankings, and celebrate champions through a dedicated Trophy Room.

## Features

- 🏆 Trophy Room showcasing every tournament winner
- ⚽ Tournament history and results
- 📊 Player statistics
  - Cups played
  - Goals scored
  - Goals per Cup
- 📈 Power Rankings to compare players
- 🏟️ Custom tournament brackets
- 🌐 Simple and modern football themed interface

## About

Created for the DLS community, DLS26Tournament Hub turns casual matches into organized competitions. It provides a central place to track tournaments, player achievements, and the history of every DLS Cup.

From group stages to finals, every competition can be followed and remembered.
